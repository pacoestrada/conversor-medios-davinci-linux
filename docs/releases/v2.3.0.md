## Conversor de medios 2.3.0 · by Paco Estrada

Esta versión conserva las dos direcciones de conversión de la 2.2.0 y añade:

- Nuevo icono oficial con la firma «by Paco Estrada».
- Primer paquete RPM para Fedora, Rocky Linux, AlmaLinux y RHEL.
- Paquete DEB actualizado para Debian, Ubuntu y Linux Mint.
- Los cinco tamaños estándar del icono se instalan con ambos paquetes.

### Instaladores

- `conversor-mp4-mov_2.3.0_all.deb`
- `conversor-mp4-mov-2.3.0-1.noarch.rpm`

El vídeo sigue copiándose sin recodificar. Para editar, el audio se convierte a
PCM de 24 bits a 48 kHz; para publicar, se convierte a AAC a 256 kb/s.
