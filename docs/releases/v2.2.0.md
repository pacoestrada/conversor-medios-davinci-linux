## Conversor de medios 2.2.0 · Compilando Podcast

Esta versión añade **MOV → MP4 con audio AAC** al conversor existente y una
pantalla inicial con el logo de Compilando Podcast.

- **Para editar:** MP4 → MOV con PCM de 24 bits a 48 kHz.
- **Para publicar:** MOV → MP4 con AAC a 256 kb/s y 48 kHz.
- El vídeo se copia sin recodificar en ambos modos.
- Se verifican la huella del vídeo, todas las pistas de audio, sus canales,
  el códec, la frecuencia de muestreo, la duración y la lectura completa del audio.
- Se mantienen los originales y se omiten los destinos ya existentes.
- Los fallos se explican y las salidas temporales se eliminan.
- Nueva pantalla azul/violeta con logo y lanzador actualizado.

### Instalar o actualizar

Descarga `conversor-mp4-mov_2.2.0_all.deb` y ábrelo con el instalador de paquetes.
También puedes ejecutar:

```bash
sudo apt install ./conversor-mp4-mov_2.2.0_all.deb
```

El nombre del paquete se conserva para actualizar la instalación anterior.
Se añaden Python 3 y Tkinter como dependencias de la nueva pantalla.

### Compatibilidad

El modo de publicación no convierte el vídeo a H.264. Si el MOV contiene un
códec que FFmpeg no puede copiar a MP4, como ProRes o DNxHR, se informa del fallo.
Para una distribución habitual, exporta desde DaVinci con vídeo H.264.
Los archivos sin audio se conservan sin añadir pistas ficticias.
La comprobación no sustituye una prueba de importación en DaVinci Resolve.

### Validación

Pruebas con FFmpeg real en ambas direcciones: audio mono/estéreo, múltiples
pistas, archivos sin audio, vídeo intacto, destinos existentes, archivos dañados,
vídeo incompatible con MP4 y fallos de verificación. Pantalla inicial renderizada
y acción de publicación comprobada.
